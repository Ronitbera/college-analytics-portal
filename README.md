# College Analytics & Reporting Portal

An interactive single-page web dashboard for real-time visualization, department-level metric tracking, and academic performance analysis across student cohorts.

## 🚀 Live Demo
🔗 **[Launch Live Application](https://ronitbera.github.io/college-analytics-portal/)**

---

## ✨ Key Features
* **Dynamic KPI Tracking:** Computes total student count, cohort-wide average CGPA, and placement success percentage in real time based on active filters.
* **Interactive Data Visualizations:** Built with Chart.js to render department enrollment bar charts and CGPA distribution breakdown doughnuts.
* **Multi-Parameter Filtering:** Filter records by department, placement status, or perform instant fuzzy searches across student names and roll numbers.
* **Responsive Layout:** Engineered using CSS Grid and Flexbox for mobile, tablet, and desktop viewports.
* **Asynchronous-Ready Architecture:** Clean decoupled logic structured for REST API integration and dynamic JSON data updates.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, Custom CSS Properties), Vanilla JavaScript (ES6+)
* **Data Visualization:** [Chart.js](https://www.chartjs.org/)
* **Version Control & CI/CD:** Git, GitHub, GitHub Pages
